# ConvertMint Third-Party Source

This repository provides source code, license materials, notices, and build information for third-party open-source software distributed with ConvertMint.

ConvertMint itself is proprietary software and its source code is not included here.

## Releases

Source materials are organized by ConvertMint release.

For each release, the corresponding GitHub Release contains the source archives and checksums associated with the third-party components included in that version of ConvertMint.

## ConvertMint 1.7.2

Third-party components include, where applicable:

- FFmpeg / FFprobe and enabled external libraries
- LibreOffice and applicable bundled components
- Python
- pypdf
- WebView2 disclosures and redistribution information
- Other open-source dependencies distributed with ConvertMint

See the release assets and accompanying source index for exact versions, licenses, hashes, and correspondence to shipped binaries.

## Source Availability

Where an applicable open-source license requires source availability, the corresponding source is provided through this repository and its GitHub Releases.

SHA-256 checksums are provided so downloaded archives can be verified against the materials used to build the corresponding ConvertMint release.
